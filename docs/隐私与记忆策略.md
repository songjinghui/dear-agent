# 隐私与记忆策略

## 本机存储

- SQLite 数据库保存在 `data/companion.sqlite3`，包含本机对话会话、导入历史档案、消息、用户确认的长期记忆、Agent 设定和自动生成的会话摘要。
- 每次模型调用会自动把请求内容、模型信息和调用结果记录到同一本机数据库，可从「模型设置 → 查看模型调用记录」查看或删除。记录可能包含个人对话内容；不会自动过期，清空或逐条删除后才移除。
- API Key 单独保存到 Windows 凭据管理器，不进入数据库、普通配置文件或日志。
- 服务默认绑定 `127.0.0.1`。浏览器只访问本机 API；数据库文件不通过 API 暴露。
- 不会扫描仓库中的原始日记、附件或其他目录。

## 云端模型请求

- Agent 设定默认包含温和、坦诚的沟通方式；用户可在模型设置中修改。此设定保存在本机，并随每次请求发送给所选模型。
- 直接 API 模式会把当前会话的摘要、尚未被摘要覆盖的消息及当前输入组装后发送。上下文窗口默认按 8192 tokens 估算，可在模型设置中修改；达到输入预算约 75% 时，应用会把较早消息发给当前云端模型生成摘要，再保存摘要到本机。摘要生成会产生一次额外模型请求。会话原始消息不会被删除。
- 普通长期记忆注入默认关闭。用户打开总开关后，应用在本地检索并排除未确认、已过期及严格私密记忆；匹配到敏感记忆时，发送前展示本轮将附加的具体内容，并逐次确认。拒绝时仍发送当前问题，但不附加敏感记忆。最多附加 4 条相关记忆。
- 记忆隐私级别为普通、敏感、严格私密。严格私密记忆无论设置如何都不会进入模型提示词；敏感记忆的授权仅对当前请求和已展示的确切内容有效，修改后的内容需要重新确认。
- 可选的向量语义检索仅连接用户配置的本机 Ollama `/api/embed` 地址；保存的向量按模型和记忆内容哈希缓存在 SQLite。向量检索与 FTS 关键词检索结果合并，仍经过上述资格过滤及相关度筛选。嵌入服务缺失或出错时回退到关键词结果。
- 历史档案检索默认关闭。用户单独开启后，应用会在本机会话库搜索最多 5 个命中；已压缩当前会话中的原始消息也可检索，其他会话命中会带上邻近上下文。命中的原文会随当前模型请求发送，并保留说话方标签。
- Codex CLI 继续使用其自身线程上下文；应用仍保存本地原始消息，并把 Agent 设定及已有的会话摘要作为上下文提供。CLI 的线程压缩由 Provider 自身管理；应用当前不会在 CLI 模式下主动生成新的会话摘要。
- 会话分析只在用户从历史会话详情手动发起时运行；所选会话的全部消息会分批发送给当前配置的模型服务。分析摘要和待审核候选保存在本机；历史 AI 回复不会作为用户记忆的证据。只有用户采纳的候选才会写入长期记忆，并保存来源消息引用。此操作独立于历史检索开关。
- 模型服务商对请求的保留、训练和处理方式由服务商自己的政策决定；本应用无法代替用户核实或控制这些政策。

## 记忆生命周期

- 普通对话不会自动成为长期记忆。
- 用户在界面手动保存，或明确说「记住这个：……」时，应用保存记忆。
- 每条记忆记录类型、重要度、来源、确认状态、敏感级别和时间。
- 记忆类型与隐私级别互相独立；当前代码支持工作、情景、语义三类，感知记忆尚未接入应用数据模型。
- 用户可以在记忆界面搜索、修改和删除记忆。删除记忆时会同步删除其全文检索索引。
- 导入档案保存在同一会话/消息数据库中，并带有导入来源标记；原始导入消息只读。用户选择继续会话后，直接 API 模式可自动压缩较早上下文；CLI 仍由 Provider 管理线程上下文。历史档案界面可本机搜索和回看。
- 完整导入的历史会话可显式继续；导入消息保持不变，新增对话作为续聊记录在同一会话中保存。删除档案时移除其原始消息，续聊内容保留并转换为普通本机会话。
- 删除档案会同时删除该档案的分析摘要和待审核候选；已经采纳的长期记忆会保留。
- 删除导入档案时，若其会话被保留为普通续聊，会同时删除依赖导入原文生成的会话摘要。
- 档案导入只校验通用 JSONL 格式和大小限制；应用不会读取或核对平台原始导出。AI 转换的遗漏或改写无法由格式校验发现。
- 目前不自动过期、合并或推断记忆；这些能力可在后续阶段增加。

## 当前限制

- 本机 UI 没有额外的应用密码；请使用个人 Windows 账户保护设备。
- 本地数据库当前未加密。请将设备磁盘加密，并将备份放在自己控制的加密介质中。
- 暂不支持远程访问、附件存储、自动备份或数据恢复界面。
