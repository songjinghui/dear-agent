# A-03：长上下文连续性——执行输入

## 执行前提

在一个全新的普通聊天会话中执行。模型设置采用直接 API，`context_window_tokens=4096`、`max_tokens=350`；关闭长期记忆发送和历史档案检索。每条输入都在页面里单独发送，等完整回答出现后再继续。

下列内容是用户的生活表达，不是测试提示词。不要把本文件之外的判定标准告诉模型。

## 执行输入

1. 下个月是小澄的生日。我想把以前一起拍的照片做成一本小册子送他，照片已经挑了一部分，封面大概想用深蓝色；只是还没想好去哪里印。

2. 今天下午开会比预想久，回来路上买了菜。本来只想做个快手的面，结果切菜的时候反而慢慢安静下来了。

3. 阳台那盆迷迭香这两天有点蔫，我把它搬到窗边晒了一会儿。也许只是前几天浇水太勤了，先观察几天。

4. 周末想去看一个小型摄影展，不一定要待很久，就是想给自己一点出门走走的理由。附近那家店的咖啡也还不错。

5. 这周工作里有一份说明文档总改不顺，改到后来有点烦。我先把最难的两段标出来，准备明天头脑清醒一点再看。

6. 晚上和朋友聊到她准备搬家，她说最舍不得的是家里那扇朝西的窗。我突然觉得，人记住一个地方的方式真的很具体。

7. 我把衣柜里不常穿的衣服整理出来了几件，打算周末拿去捐掉。收拾的时候发现一条围巾，原来是前年旅行时买的。

8. 今天午饭后在楼下走了二十分钟，风有点大，但回来以后没有那么困。以后下午犯困的时候，也许可以先出去绕一圈。

9. 我最近在试着少刷短视频，不是完全不看，只想把睡前那段时间空出来读几页书。昨晚确实比平时早一点放下手机。

10. 同事把她做的饼干带来分给大家，我拿到的是海盐巧克力味。其实我很少吃甜的，但那一块刚好不腻。

11. 今天回家路过花店，买了一小束洋桔梗放在餐桌上。屋子没有变得多不一样，但看见它还是会觉得心情亮一点。

12. 明天要给家里打个电话，最近都只是发消息。没有什么大事，就是想听听他们的声音，也说说我这周这些琐碎的事。

13. 下午把那份文档最难的部分重新写了一遍，终于顺了一点。还没有完全定稿，不过至少不再像昨天那样卡住了。

14. 今天晚饭后没有马上做事，就在窗边坐了一会儿。外面有人遛狗，小朋友在楼下喊来喊去，感觉一天慢慢收住了。

## 最后追问

突然想起小澄生日那件事：我当时准备送他什么？现在还缺哪一步？

## 若尚未触发压缩

先在页面的“模型调用记录”检查是否已出现一次目的为“会话压缩摘要”的记录。没有才继续补发下列两条，再发送一次最后追问；不要改变最后追问的内容。

- 今天洗完澡以后把床单换了，浅色的那套晾在阳台上。做完这种小事以后，晚上好像更容易安定下来。
- 我翻了翻下周的日程，发现周三晚上是空的。暂时不想安排什么，留出来做饭或者随便走走都行。
